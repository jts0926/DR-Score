# Synthetic inference example

`synthetic_bilateral_knee_example.png` is a fully synthetic, AI-generated
bilateral knee radiograph supplied solely to demonstrate the inference
workflow. It contains no source-cohort image or participant data. Its anatomy
and model outputs are illustrative and must not be used for clinical purposes.

Source-cohort medical images are not included in this repository. To test an
authorised local image, pass its path directly to `scripts/infer_bilateral.py`;
medical images remain ignored by Git.
